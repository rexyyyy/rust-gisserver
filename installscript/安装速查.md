# rust-gisserver 安装速查（Windows）

> 一页纸版本，作为首选入口。四份安装手册（01/02 数据库篇、03/04 Setup 篇）已按本文口径重生成，
> 与本文一致；如仍有冲突，以本文为准。手册源文件为同目录 `0*.md`，改后运行 `python gen_manuals.py` 重出 PDF。

## 一句话结论

装完 PostgreSQL + PostGIS 后，**只需一条命令**建库初始化，不用手写 10 页 PDF 里的 CREATE DATABASE / CREATE EXTENSION / 三条 psql。

```powershell
powershell -ExecutionPolicy Bypass -File "安装目录\sql\init_all.ps1" -Password "你的postgres密码"
```

可从任意目录运行；脚本自己找 psql、自己定位 SQL 文件、任一步失败立即停并报错。

## 三步走

| 步骤 | 做什么 | 关键点 |
| --- | --- | --- |
| 1 | 装 PostgreSQL 16 x64 | 端口 **5432**（默认值，不要改动）；装到 `D:\PostgreSQL\16` 之类**无中文无空格**路径 |
| 2 | 装 PostGIS 3.5（bundle 版） | 安装目录必须**与 PostgreSQL 完全一致**；组件默认全选；不创建示例库 |
| 3 | 跑 `sql\init_all.ps1` | 一条命令建库 + 启用 PostGIS + 灌入 system/map 两张表；**失败会明确报错不会假成功** |

装完服务前，把 `run-env\.env`（或安装目录 `.env.example` 复制出的 `.env`）里
`MANAGER_DB_PASSWORD` / `MAPSERVER_DB_PASSWORD` 改成第 3 步用的密码即可。

## 统一口径（全项目只认这一套）

| 项 | 值 | 说明 |
| --- | --- | --- |
| 端口 | **5432** | 全项目统一 5432（Windows 原生安装、Docker 宿主映射均一致）；若宿主已占用 5432，在 `.env` 里同步改三个端口变量 |
| 数据库名 | `mapserver-manager` | 短横线，不是下划线 |
| 用户 | `postgres` | 超级用户 |
| 编码 | UTF8 | **不指定** `LC_COLLATE` / `LC_CTYPE`；Windows 上写 `en_US.UTF-8` 会直接报错 |
| 扩展 | 只装 `postgis` 一个 | 代码只用核心空间函数（ST_Transform / ST_AsMVTGeom / geometry_columns 等）；topology / sfcgal / tiger_geocoder / fuzzystrmatch 均不需要 |
| SQL 顺序 | `01-init-database.sql` → `system.sql` → `map.sql` | 三个脚本都幂等，失败修完直接重跑 |

## 常见报错对照表

| 报错 | 原因 | 处理 |
| --- | --- | --- |
| `locale "en_US.UTF-8" does not exist` | 照旧 PDF / 旧脚本手写了 POSIX locale | 用现成的 `01-init-database.sql`（只写 `ENCODING 'UTF8' TEMPLATE template0`） |
| `could not open extension control file ... postgis.control` | PostGIS 没装到 PostgreSQL 同一目录 | 卸载 PostGIS 重装，Installation Directory 选 `D:\PostgreSQL\16` |
| `role "postgres" does not exist` / 密码不对 | 密码没传或 `.env` 没同步 | 脚本加 `-Password`；装完把 `.env` 两个 `*_DB_PASSWORD` 改成同一个 |
| `psql.exe not found` | 进程 PATH 没 PostgreSQL | 脚本会自动查注册表和常见盘符；仍找不到就把 `...\PostgreSQL\16\bin` 加 PATH |
| 脚本打印 `✅完成` 但服务连不上库 | 旧 `init_all.ps1` 没检查 psql 退出码（假成功） | 用当前脚本：每步 `-v ON_ERROR_STOP=1` + `$LASTEXITCODE` 校验，失败即停 |
| 中文乱码 | 客户端编码不匹配 | `chcp 65001` 或 `$env:PGCLIENTENCODING="UTF8"` |
| 5432 被占用 | 本机已有别的 PostgreSQL / Docker 映射冲突 | 换端口时脚本 `-Port`、`.env` 两个 `*_DB_PORT`、docker-compose 的 `${MAPSERVER_DB_PORT:-5432}` 要一起改 |

## 手工方式（脚本跑不了时）

```powershell
cd /d "D:\PostgreSQL\16\bin"
$env:PGPASSWORD = "你的postgres密码"
psql -U postgres -p 5432 -v ON_ERROR_STOP=1 -f "安装目录\sql\01-init-database.sql"
psql -U postgres -p 5432 -d mapserver-manager -v ON_ERROR_STOP=1 -f "安装目录\sql\system.sql"
psql -U postgres -p 5432 -d mapserver-manager -v ON_ERROR_STOP=1 -f "安装目录\sql\map.sql"
```

## 验证

```sql
SELECT extname, extversion FROM pg_extension WHERE extname = 'postgis';   -- 应返回 1 行 3.5.x
SELECT count(*) FROM sys_user;        -- 非 0
SELECT count(*) FROM sys_menu;        -- 非 0
SELECT count(*) FROM map_datasource;  -- 表存在即可，可为 0
```

看到 PostGIS 版本号 + 系统表有数据行数，数据库这层就算过了。
